# continuar-jornada

Use `session_search` para localizar a sessão anterior e `todo` para reconstruir o progresso. Não dependa de flags em arquivos locais. Mostre em uma frase onde parou, qual evidência existe e o próximo passo. Se não houver evidência, diga que não foi possível confirmar e ofereça a menor verificação.
