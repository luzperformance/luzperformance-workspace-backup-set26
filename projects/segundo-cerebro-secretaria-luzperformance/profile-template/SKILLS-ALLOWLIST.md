# Skills permitidas — fase inicial

## Pode usar

- `operacional/wiki-ingest`: capturar links e referências operacionais; excluir qualquer dado de paciente.
- `operacional/workspace-information-architecture`: manter materiais operacionais encontráveis.
- `planejamento/writing-plans`: transformar processos grandes em plano verificável.
- `content/clinical-authority-content`: apenas para rascunhos revisáveis, respeitando limites de conteúdo clínico e sem publicação autônoma.
- `content/heygen-avatar-reels`: apenas para preparar roteiros/captions para revisão.
- `productivity/document-to-action-items`: extrair tarefas de documentos autorizados e não clínicos.
- `productivity/meeting-action-items`: organizar decisões e pendências de reuniões operacionais.

## Não usar sem uma expansão formal de escopo

- Calendário, e-mail, mensageria, CRM, cron, pagamentos, hospedagem, DNS ou canais sociais.
- Skills de pesquisa/armazenamento clínico ou que possam receber dados de pacientes.
- Qualquer skill que publique, envie, compre, altere segurança ou conecte uma integração.

## Regra

Antes de instalar ou liberar uma skill, avaliar: dados que ela acessa, ação externa possível, necessidade real e como será verificada. A aprovação de uma skill não aprova automaticamente o envio/publicação que ela possa viabilizar.
