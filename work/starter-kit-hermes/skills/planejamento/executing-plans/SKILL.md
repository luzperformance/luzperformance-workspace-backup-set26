# executing-plans

Leia plano e contexto do projeto. Use `todo`, execute em lotes pequenos e valide após cada marco. Pare diante de divergência estrutural ou risco não previsto. Atualize o plano com evidências; não marque como concluído só porque o código foi escrito.
