# Como colar no HeyGen

1. Avatar IV / Create video → Script
2. Cola o bloco **COLA ISTO** de um arquivo só
3. Caption nativa ligada
4. Velocidade 1.0. Não acelera.
5. Look: trava o da Roleta (close, fundo escuro, blazer). Um gêmeo só.
6. Não cola tag de emoção. Não cola CTA de receita.

Meta: 45 a 60s. Se o HeyGen passar de 65s, corta o último parágrafo antes do CTA e regenera.

Nunca vende receita. CTA = consultoria / link na bio.
