# backup-workspace-github

Verifique `.gitignore` antes do primeiro commit. Exclua `.env`, chaves, `auth.json`, bancos, logs e sessões. Inicialize Git só com consentimento, use repositório privado e confirme remoto antes do push. Mostre `git status --short`, commit e resultado real do push. Não versionar todo `$HERMES_HOME`.
