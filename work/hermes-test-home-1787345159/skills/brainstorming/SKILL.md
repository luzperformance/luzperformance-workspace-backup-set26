# brainstorming

Explore objetivo, usuário, restrições e critério de sucesso. Apresente 2–4 opções com trade-offs e peça uma decisão quando ela mudar o projeto. Não implemente durante brainstorming. Registre a decisão no documento do projeto, não em memória global salvo se for preferência estável.
