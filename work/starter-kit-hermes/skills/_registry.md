# Registry de skills Hermes

Todas as skills abaixo são instaladas em `$HERMES_HOME/skills/<nome>/`. Use `hermes skills list`, `hermes skills check` e uma nova sessão após instalação.

- `backup-workspace-github` — Use quando configurar backup Git privado do projeto.
- `brainstorming` — Use antes de criar solução quando requisitos estão abertos.
- `commit-diario-workspace` — Use quando criar rotina diária de commit do projeto.
- `continuar-jornada` — Use quando o usuário pedir para retomar o onboarding.
- `cron-resume-wizards` — Use quando agendar lembrete respeitoso de retomada.
- `executing-plans` — Use quando executar um plano já aprovado.
- `gera-log-jornada` — Use quando gerar relatório verificável do onboarding.
- `onboarding-checklist` — Use quando iniciar ou revisar a configuração do Hermes.
- `primeira-vitoria` — Use após o setup para entregar uma primeira vitória real.
- `seguranca-checklist` — Use para auditar segurança e privacidade do Hermes.
- `verification-before-completion` — Use antes de afirmar que uma tarefa terminou.
- `wizard-agente` — Use quando definir identidade e regras do agente Hermes.
- `wizard-aluno` — Use quando registrar preferências estáveis do usuário.
- `wizard-autonomia` — Use quando configurar aprovações e limites de autonomia.
- `wizard-conectar` — Use quando conectar modelo, ferramentas, busca e gateway.
- `wizard-whatsapp` — Use quando conectar WhatsApp ao gateway Hermes.
- `wizard-whisper-quick` — Use quando configurar transcrição de voz no Hermes.
- `wizard-workspace` — Use quando criar contexto e estrutura de projeto Hermes.
- `writing-plans` — Use quando transformar uma decisão em plano executável.
