# Meeting-link capture

## Reliable handling

A Google Meet link is an access endpoint, not calendar metadata. Public fetches may return only browser-compatibility or sign-in pages. Record the link unchanged, note that title/time/participants are unavailable, and wait for calendar details before treating it as a commitment.

## Safe record fields

- capture date/time and timezone
- original link
- status: received / pending linkage
- next action: link to a confirmed calendar event when title and time are known

Never join the meeting, create a calendar event, or notify participants from a bare link alone.
