# writing-plans

Crie plano com escopo, arquivos, passos pequenos, testes, riscos e rollback. Use caminhos reais depois de inspecionar o projeto. Não invente comandos. Para um plano persistente, salve em `.hermes/plans/` se o projeto adotar essa convenção.
